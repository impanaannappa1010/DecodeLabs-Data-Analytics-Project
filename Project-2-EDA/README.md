# Exploratory Data Analysis (EDA) – DecodeLabs Project 2

## About the Project
This project focuses on Exploratory Data Analysis using Python. It analyzes a sample sales dataset to identify patterns, trends, sales performance, and outliers.

**Note:** The dataset was created for practice because no separate dataset was provided.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Project Files
- `eda_analysis.py` – Python code for data analysis.
- `sales_data.csv` – Sample sales dataset.
- `product_sales.png` – Product-wise sales graph.
- `monthly_sales.png` – Monthly sales graph.
- `sales_distribution.png` – Sales distribution graph.
- `sales_boxplot.png` – Sales boxplot.
- `Project_Documentation.md` – Detailed project report.

## Key Findings
- Total sales: ₹22,30,000.
- Total orders: 20.
- Laptops recorded the highest product sales.
- The West region recorded the highest regional sales.
- March recorded the highest monthly sales.
- Order 120 was identified as an outlier.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib seaborn`
3. Run the program:
   `python eda_analysis.py`

## Learning Outcomes
Learned data analysis, descriptive statistics, data visualization, trend identification, and outlier detection using Python.
